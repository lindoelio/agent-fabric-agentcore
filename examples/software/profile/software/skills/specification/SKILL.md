---
name: specification
description: Turn an ambiguous software request into concrete acceptance criteria and a bounded plan.
---

1. Inspect the existing project and identify the user's intended result.
2. Record assumptions; ask only questions that materially change implementation.
3. Define inputs, outputs, failure behavior, and observable acceptance criteria.
4. Propose the smallest useful implementation and appropriate verification.
5. Return the specification to the coordinating agent before substantial coding.
